This repository showcases my projects, highlighting data cleaning, visualization, and analysis skills. It includes real-world examples where I apply Python, Power BI, and other tools to extract insights and drive data-driven decisions.
### Energy_Demand_Forecasting_ARIMAX_SARIMAX
**Spanish Version**
Desarrollé un modelo ARIMAX para la predicción de la demanda de energía en Colombia, iniciando con un análisis exploratorio de datos (EDA), limpieza de la base y verificación de estacionariedad, multicolinealidad y correlaciones entre variables. Implementé transformaciones logarítmicas y técnicas de escalamiento con el fin de mejorar el desempeño del modelo, aunque sin resultados significativos. Posteriormente, construí un modelo SARIMAX, el cual mostró un rendimiento superior y mayor capacidad predictiva en la serie temporal.
**English Version**
Developed an ARIMAX model for forecasting energy demand in Colombia, starting with exploratory data analysis (EDA), dataset cleaning, and verification of stationarity, multicollinearity, and variable correlations. Applied logarithmic transformations and scaling techniques to enhance model performance, but with limited improvement. Consequently, built a SARIMAX model, which demonstrated superior performance and higher predictive accuracy for the time series.
### Regression Models
**Spanish Version**
Realicé modelos de regresión para predecir las ventas de carros, utilizando distintos enfoques como regresión lineal, regresión polinómica, árboles de decisión, regresión con Random Forest, vectores de soporte, regresión Ridge y regresión Lasso, con el fin de comparar su rendimiento y capacidad predictiva.
**English Version**
Developed regression models to forecast car sales, applying different approaches such as linear regression, polynomial regression, decision trees, Random Forest regression, support vector regression, Ridge regression, and Lasso regression, in order to compare their performance and predictive accuracy.
